Perspective

How I build products

Make agents useful in the real world

The value of an AI agent is not the demo. It is whether a security team can trust it in a real workflow. I focus on the platform, partner experience, and product path that help useful agents reach enterprise customers.

Partner success is a product outcome

A platform wins when partners can build, ship, and grow with confidence. That makes developer experience, clear APIs, trustworthy requirements, and a path to customers core product work, not supporting details.

Learn from the smallest reliable release

My SRE background shaped how I work: start with the smallest dependable release that can answer a real question, measure what happens, and use the signal to decide what to build next.
